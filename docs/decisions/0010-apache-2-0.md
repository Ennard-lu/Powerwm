# ADR-0010: 采用 Apache License 2.0

- 状态：Accepted
- 日期：2026-11-24
- 决策者：powerwm 维护者
- 相关：[README.md](../../README.md)、[CONTRIBUTING.md](../../CONTRIBUTING.md)、[ADR-0005](0005-license.md)

## 背景

ADR-0005 并列了 MIT、Apache-2.0、MIT OR Apache-2.0、GPL-3.0、LGPL-3.0 等候选，但未做决定。项目现在确定使用 **Apache-2.0**。

## 决策

1. 项目许可证为 **Apache License 2.0**。
2. 根目录添加完整 `LICENSE` 文本。
3. 源文件使用 `SPDX-License-Identifier: Apache-2.0`。
4. `CONTRIBUTING.md` 明确：贡献以 Apache-2.0 授权，无需 CLA。
5. 第三方代码/协议 XML 保留其原始许可证与版权声明；引入前检查兼容性。

## 后果

### 正面

- 宽松许可证，允许商业使用、修改、闭源分发。
- 包含明确的专利授权与贡献者条款，降低法律风险。
- 与大量 Linux/Wayland 生态项目兼容。
- SPDX 标识便于自动化审计。

### 负面 / 代价

- 不强制下游回馈修改。
- 需要保留版权/许可声明与 NOTICE（若存在）。
- 与 GPLv2-only 代码的兼容性需要逐案评估。

### 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 第三方许可证不兼容 | 引入前审计；保留 SPDX/版权 |
| 贡献者未授权 | CONTRIBUTING 明确；PR 模板提示 |
| 专利条款争议 | 保留 LICENSE 原文；必要时法律咨询 |

## 备选方案

| 方案 | 优点 | 缺点 | 为何未选 |
| --- | --- | --- | --- |
| MIT | 极简、采用门槛低 | 无专利条款 | 缺少专利保护 |
| MIT OR Apache-2.0 | 下游灵活 | 双许可管理复杂 | 单一 Apache-2.0 已满足 |
| GPL-3.0 | 强制回馈 | 商业采用受限 | 与项目采用目标冲突 |
| LGPL-3.0 | 库可广泛链接 | 合成器整体仍复杂 | 不适合作为整体许可证 |

## 重新审视条件

- 项目希望强制下游回馈，且维护者愿意承担采用率下降。
- 关键依赖的许可证与 Apache-2.0 不兼容，且无法隔离。
